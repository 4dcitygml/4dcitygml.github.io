# Cities

This is the list of 4dcitygml city repositories. Each repository's
`4dcitygml.json` is authoritative for its settings (coordinate system, stable
building ID, data folders, attribution, licence); its `NOTICE` records the
source dataset.

| City | Repository | Country | Configuration |
|---|---|---|---|
| Tokyo Station | [sample-tokyo-station](https://github.com/4dcitygml/sample-tokyo-station) | JP | [4dcitygml.json](https://github.com/4dcitygml/sample-tokyo-station/blob/main/4dcitygml.json) |
| Munich Hauptbahnhof | [sample-munich-station](https://github.com/4dcitygml/sample-munich-station) | DE | [4dcitygml.json](https://github.com/4dcitygml/sample-munich-station/blob/main/4dcitygml.json) |
| Grand Central | [sample-newyork-station](https://github.com/4dcitygml/sample-newyork-station) | US | [4dcitygml.json](https://github.com/4dcitygml/sample-newyork-station/blob/main/4dcitygml.json) |

The three are compact demonstration datasets. They differ on purpose in
source standard, coordinate system, units and building identifier, so the
shared tools are tested against each.

To add a city, start from [city-template](https://github.com/4dcitygml/city-template)
and propose a row for this table in the
[site's repository](https://github.com/4dcitygml/4dcitygml.github.io).
